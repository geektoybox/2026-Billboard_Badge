# Release notes

The reader supports formatted books with additional punctuation and accented
characters. The included sample books have precomputed indexes for each font
and text size. The font files require additional space on the badge.

Some books in the Starter Library are large, and downloading them may require
more free space than is available alongside other badge applications. If a
book does not fit, remove files or applications you no longer need and try
again. The reader does not remove other applications automatically.
